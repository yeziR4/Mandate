Cost note: this is the *cheap* mode. Registering with a self-contained `data:` URI costs
671k–694k gas per agent (**0.082 METIS** total) because the whole 730-byte document goes into
storage. Hosting the JSON and passing a 40-byte URL is 3.7× cheaper and is what indexers expect.

## Metadata

The ten files are generated by the plan run into `web/public/agents/*.json`, so they are served by
the site the moment it deploys. Shape follows the ERC-8004 recommendation (`type`, `name`,
`description`, `image`, `services`, `supportedTrust`):

```json
{
  "type": "https://eips.ethereum.org/EIPS/eip-8004#registration-v1",
  "name": "Mandate — GPT",
  "description": "A treasury agent holding a real m.USDC purse on Metis under a written mandate. Scenario 1, agent 1 of 10. Break the mandate and the purse transfers to you.",
  "image": "https://<site>/mark.svg",
  "services": [
    { "name": "web", "endpoint": "https://<site>" },
    { "name": "contract", "endpoint": "eip155:1088:<MandateArena>" }
  ],
  "x402Support": false,
  "active": true,
  "supportedTrust": ["reputation"]
}
```

Two fields are deliberately absent:

- `registrations` — it needs `{ agentRegistry, agentId }`, and the agent id does not exist until the
  mint. Adding it later means a second `setAgentURI` per agent (+10 transactions). Not worth it for
  a pilot; the URI is already bound by the NFT itself.
- `agentWallet` — the keeper signs verdicts on behalf of all ten, so no per-agent wallet is set.
  `setAgentWallet` can be added later without re-registering.

## What execution does

Ten sequential `register(string)` calls from `DEPLOYER_PRIVATE_KEY`, one per model. Each mints an
NFT owned by the deployer and stores the URI. The script reads each agent id out of the ERC-721
`Transfer` log rather than assuming a counter, then writes `deployments/agents-<name>.json`.

**Registration is effectively permanent.** There is no `burn` in the registry ABI; the identity NFT
can only be transferred. Treat the ten slots as spent.
